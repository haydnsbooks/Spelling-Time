# Security

We take the security of our project seriously. If you believe you have found a security vulnerability, please do not disclose it publicly via public GitHub issues, discussions, or pull requests.
Instead, please report it via private disclosure:
• Report via [private vulnerability reporting](https://github.com/haydnsbooks/Spelling-Time/security)
• Include the following information:
	• Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting).
	• Full paths of source file(s) related to the behavior.
	• The location of the affected source code (tag/branch/commit or direct URL).
	• Any special configuration required to reproduce the issue.
	• Step-by-step instructions to reproduce the vulnerability.
	• Proof-of-concept (PoC) or exploit code.
	• An assessment of the potential impact.
  • CVE, where appropiate.

Response Process

When you report a vulnerability, our team follows this process:
1. Acknowledgment: We will acknowledge receipt of your report within 48 hours and provide an initial assessment.
2. Investigation: We will investigate the issue, verify the impact, and coordinate with you if we need further details.
3. Remediation: We will develop a fix, test it thoroughly, and prepare a patch or new release.
4. Disclosure: We will coordinate the public disclosure timeline with you, publish a security advisory, and credit you for the responsible disclosure (unless you prefer to remain anonymous).
